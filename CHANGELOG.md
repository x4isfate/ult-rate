# Changelog

## 0.5.0 — test build

First working version, first public release on GitHub.

- Left-toolbar ★ button: the hub for the GM, the rating window for players.
- Rating window: four compact criteria and one wide criterion, custom 1–10 integer sliders (mouse, touch and keyboard), sliding numbers, description popovers, optional notes, thank-you screen, edit-after-submit when the GM allows it.
- GM hub: start a round (name, date, system auto-filled, anonymous / notes / editing options, participants who are connected now), live progress, reminders, close or cancel, results per session, trend chart, settings.
- Editable criteria with recommended wording, colour settings (Idaris by default) with live preview, defaults for new rounds, JSON export.
- English, Russian and German.
