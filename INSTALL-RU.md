# Установка тестовой версии ULT's Session Rating 0.5.0

## Установка в Foundry (рекомендуется)

1. В Foundry откройте **Add-on Modules → Install Module**.
2. В поле **Manifest URL** вставьте:
   ```
   https://github.com/x4isfate/ult-rate/releases/latest/download/module.json
   ```
3. Нажмите **Install**, затем включите модуль в мире (**Manage Modules**).

Дальше новые версии приходят обычной кнопкой **Update** в списке модулей.

## Установка вручную (без интернета)

Архив `ult-rate.zip` лежит в релизе: <https://github.com/x4isfate/ult-rate/releases/latest>

1. Закройте Foundry (или вернитесь в главное меню).
2. Распакуйте архив (или скопируйте папку `ult-rate` целиком) в папку модулей Foundry:
   `%localappdata%\FoundryVTT\Data\modules\ult-rate`
   (или в `Data\modules` внутри той папки данных, которую использует ваш Foundry).
   Внутри `ult-rate` должен лежать `module.json` — не `ult-rate\ult-rate\module.json`.
3. Запустите Foundry, откройте мир → **Game Settings → Manage Modules** → включите **ULT's Session Rating** → сохраните. Мир перезагрузится.
4. Слева в панели инструментов (группа токенов) появится кнопка ★.
   - У ведущего она открывает окно управления.
   - У игроков — окно оценки (когда идёт оценивание).

## Как проверить в одиночку

В окне запуска у ведущего в списке участников есть строка с вашим именем и пометкой «ведущий · для теста». Отметьте её — и окно оценки откроется у вас самих, а голос попадёт в ту же систему, что и голоса игроков. Так можно пройти весь путь до итогов и графика без второго человека. Для проверки анонимности и «живого» обмена нужен хотя бы один игрок в другом браузере.

## Где лежат данные

Голоса хранятся в записи журнала **«ULT's Session Rating — data (do not delete)»**. Она закрыта для игроков, удалять её не нужно — иначе пропадёт вся история оценок.

## Как удалить

Отключите модуль и удалите папку `ult-rate`. Запись журнала можно удалить вручную, если история больше не нужна.
